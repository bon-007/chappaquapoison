2. **Re-sending:** Image shared across multiple conversations
   - Shows image importance (repeated use across contexts)

3. **Sync Operations:** iCloud backup or device synchronization created duplicates
   - Multiple devices storing same image
   - Backup/restore operations preserving multiple copies
   - Indicates intentional preservation

4. **Backup Copies:** Multiple versions indicating deliberate archiving
   - Documents of critical evidence
   - Preserved against future loss or deletion
   - Shows anticipation of legal proceedings

## TECHNICAL METHODOLOGY

### Analysis Process

**1. Database Query**
SQLite3 query of chat.db attachment table (iMessage database):
- Retrieved 1,805 image attachment references
- Filtered for image MIME types (image/jpeg, image/png)
- Resolved message table entries to attachment files

**2. File Location Mapping**
Resolved Library/Messages/Attachments/ paths to actual disk locations:
- Primary Attachments folder structure mapped
- Secondary "Tara Messages," "Tara Screenshots," "Tara Texts" folders inventoried
- All image files validated on disk (3,577 total located)

**3. PIL Image Analysis**
Opened each image with Python PIL (Pillow) library:
- Extracted image dimensions
- Validated color mode (RGB, RGBA, etc.)
- Verified image integrity (no corruption)
- Generated file size statistics

**4. EXIF Metadata Extraction**
Used piexif library for comprehensive EXIF parsing:
- Extracted 0th IFD tags (basic image information)
- Extracted EXIF IFD tags (camera metadata)
- Preserved camera model identification
- Captured datetime taken for temporal analysis
- Documented orientation and resolution data

**5. Fingerprinting and Hashing**
Calculated SHA256 hash for each image:
- Identified exact duplicates (same hash)
- Useful for source tracking
- Verified file authenticity and integrity
- Enabled duplicate image network analysis

**6. Screenshot Detection**
Matched image dimensions to known device specifications:
- Identified PNG format files (screenshot indicator)
- Matched dimensions to iPhone/Android screen sizes
- Classified by device type (iPhone 6, 6s, X, 11, etc.)
- Noted standard screenshot creation patterns

**7. Categorization and Classification**
Applied multi-factor categorization:
- Keyword matching in filenames
- EXIF model analysis for device identification
- Dimension analysis for content type inference
- Manual review of sample images in each category
- Classification into 13 evidence categories based on forensic relevance
